ETIQUETAS DE CASES

Preencher etiqueta

Preenche os dados, adiciona uma fotografia e gera o PDF pronto a imprimir.

Conteúdo

Escolhe os elementos de cada coluna. A letra ajusta-se ao espaço disponível no PDF.

Elementos

Coluna direita

JPG ou PNG, até 10 MB. A imagem mantém as proporções.

Descarregar PDF
Os dados e a fotografia são processados apenas neste navegador.

Pré-visualização

Modelo original. Clica em «Gerar PDF» para ver o resultado.

Na impressão, seleciona «Tamanho real» / 100% para manter as dimensões do modelo.
